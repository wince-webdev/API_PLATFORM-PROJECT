# API Platform Project - Symfony

Projet personnel réalisé dans le cadre de l’apprentissage et de la pratique de la création d’API REST modernes avec Symfony et API Platform.

## Présentation

Cette application m’a permis d’approfondir la configuration et le développement d’API avec Symfony, ainsi que les tests d’endpoints via Postman.

## Fonctionnalités travaillées

- Création d’API REST avec API Platform
- Configuration des routes API
- Gestion des entités avec Doctrine ORM
- Sérialisation des données
- Tests des endpoints avec Postman
- Gestion des requêtes HTTP
- Architecture backend avec Symfony
- Manipulation des réponses JSON
- Mise en place de ressources API

## Technologies utilisées

- PHP 8
- Symfony
- API Platform
- Doctrine ORM
- Twig
- MySQL
- Postman

## Objectif du projet

Ce projet personnel a été développé dans le but de pratiquer la conception d’API REST avec Symfony et de mieux comprendre les mécanismes de communication backend/frontend.

## État du projet

Projet d’apprentissage et d’expérimentation technique toujours évolutif.
